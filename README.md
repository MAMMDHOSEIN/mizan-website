# میزان | میز کار قضایی

رابط فارسی و راست‌به‌چپ بر اساس Mizan Technical Blueprint v2، با React، TypeScript و Vite.

## اجرا

```sh
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 3000
```

```sh
npm run build
npm run preview -- --port 3000
```

امکانات: پیشخوان کیفری و مدنی، فیلتر و جست‌وجو، ایجاد پرونده نمونه، مرور اسناد و منشأ گزاره‌ها، تأیید مرور وقایع، تحلیل نمونه، ویرایش، ذخیره محلی و دریافت یادداشت متنی؛ نمایش واکنش‌گرا و فونت Estedad همراه برنامه.

این نسخه نمونه رابط کاربری است. داده‌ها ساختگی و ذخیره‌سازی در localStorage همین مرورگر است. احراز هویت، مجوز پرونده، پایگاه داده، OCR، اسکن فایل، بانک قوانین، موتور AI، ممیزی رسمی و ثبت قضایی پیاده نشده‌اند. اطلاعات واقعی یا محرمانه وارد نکنید. متن خروجی رأی رسمی نیست.

## تنظیمات ظاهر

از منوی تنظیمات، فونت، اندازه و وزن متن، فاصله خطوط و حروف، حالت نمایش، رنگ تأکیدی، کنتراست، تراکم و عرض چیدمان، گردی گوشه‌ها، سایه، حرکت آیکون‌ها و تصویر پیشخوان را تغییر دهید. تغییرات بلافاصله اعمال و با کلید mizan-appearance-v1 در localStorage همان مرورگر ذخیره می‌شوند. دکمه بازگردانی ظاهر، تنظیمات را به پیش‌فرض برمی‌گرداند و پرونده‌ها را تغییر نمی‌دهد. فونت‌های استعداد و وزیرمتن به‌صورت محلی همراه برنامه هستند؛ Tahoma و فونت سیستم وابسته به فونت‌های نصب‌شده دستگاه‌اند.
